## 1. Глобальные бюджеты (действуют на всех маршрутах)

| Метрика | Потолок | Как мерить |
|---|---|---|
| Lighthouse Performance (mobile) | **≥ 90** | Lighthouse, mobile preset, CPU 4× |
| LCP (CPU 4× + LTE) | **≤ 2,5 с** | Lighthouse / trace |
| LCP-элемент | **всегда `img`** (никогда canvas/текст) | Lighthouse «Largest Contentful Paint element» |
| CLS | **≤ 0,05** | Lighthouse |
| Вечные анимации на странице | **ровно 2** (hero-подсказка, лента брендов) | ревью кода |
| Контентные стеклянные поверхности в кадре | **≤ 2** (хром навигации — вне бюджета) | ревью |
| Пик декодированной памяти изображений | **≤ 300 МБ** | DevTools Memory / LRU-гейт кода |

**Заимствованные зависимости (потолки веса, gz):** lazy-бандл оптики
(ogl + шейдеры) **+≤60 КБ суммарно**; критический путь первой отрисовки
**+≤5 КБ gz** к отметке этапа 0 (`next-view-transitions` в layout +
инфраструктура тикера/useGaze); ogl и Kawase — только lazy-чанки.

## 4. Как мерить (инструменты в репозитории)

Нужен `npm run dev` на `:3000` (для CDP-скриптов) либо `npm run build` (для веса):

- `node scripts/diag-firstload.mjs` — первый заход vs рефреш, консоль/гидрация.
- `node scripts/cdp-audit.mjs` — белая точка FloatFrame (±1).
- `node scripts/build-seq.mjs` — сборка секвенций, падает при превышении бюджета кадра.
- `node scripts/validate-catalog.mjs` — санити каталога и GLB-гейт (появляется этапом 11).
- Lighthouse mobile: DevTools → Lighthouse → Mode «Navigation», Device «Mobile», CPU throttling 4×.
- Мобильная эмуляция: DevTools 390×844 + CPU 4×, прогон тяжёлых эффектов 5+ минут.
