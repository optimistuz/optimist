# optimist.md — полная спецификация сайта «Оптимист»

> **Назначение.** Это исчерпывающий слепок проекта от нуля до текущей стадии:
> что сделано, как устроено, где лежит, как работает каждая секция, анимация
> и переход. Документ написан так, чтобы по нему можно было продолжить работу
> в **Claude Web** без доступа к истории чатов. Технический, но без
> предположений — всё сверено с кодом на коммите `cadf8c6`.
>
> Рядом живут три обязательных источника правды:
> - **`CLAUDE.md`** — рабочие правила и дизайн-законы (что можно, что нельзя).
> - **`PROJECT.md`** — исходное ТЗ (контент, контакты, открытые вопросы).
> - **этот файл** — как именно всё реализовано.
>
> При расхождении: `CLAUDE.md` задаёт *правила*, этот файл описывает *факт*.

## 0. TL;DR за минуту

- Премиальный одностраничный сайт-витрина сети оптик «Оптимист» (Ташкент).
- Next.js 14 (App Router) + TypeScript + Tailwind + Motion (Framer Motion) +
  Lenis. Деплой на Vercel. Одна зависимость-исключение: `@mediapipe/tasks-vision`
  (подбор оправ по лицу через камеру).
- Главная (`/`) = одна длинная страница из ~16 секций. Есть кастомная 404.
- Сквозная дизайн-идея — **«Наведение резкости»**: всё проявляется из лёгкого
  расфокуса в резкость; интерфейс ведёт себя как зрение, которому подобрали очки.
- Фирменные «фишки»: прелоадер-«глаза» `op`, симулятор близорукости/
  дальнозоркости (шторка), «парящие оправы» на `mix-blend-mode: multiply`,
  глава-чертёж «Мастерская», квиз подбора, **подбор оправы по камере** с
  классификацией формы лица и материальным AR-рендером оправы, матовое стекло,
  «швы наводки» между главами.
- Весь контент — в одном файле `src/content/home.ts`. Фото — временные (Pexels),
  лежат в `public/photos/`.

## 4. Запуск, сборка, деплой

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # прод-сборка
npm run start
npm run lint
```

- Деплой — **Vercel**. Ассеты MediaPipe закоммичены в репозиторий, чтобы деплой

- Приёмка эффектов идёт **по скриншоту**, а не вслепую: `npm run dev` на :3000,

  в `tmp-frames/`. Стекло, лупу, переходы и canvas-рендер оправ доводить именно так.

## 5. Дизайн-философия: «Наведение резкости»

Системный язык всего сайта (закреплён в `CLAUDE.md`): **контент проявляется из
лёгкого расфокуса в резкость**, интерфейс ведёт себя как зрение, которому
подобрали очки.

### Словарь движения — ровно три глагола (`src/lib/motion.ts`)
1. **`focusIn`** — текст: `opacity 0→1`, `y 24→0`, `blur(8px)→blur(0)`.
2. **`maskLine`** (`maskLineChild`) — заголовки: построчная маска
   (`y 110%→0` внутри `overflow-hidden`) + анимация оси `--opsz` 20→72.
3. **`imageReveal`** — изображения: `scale 1.06→1` + `opacity` (**без blur**).

Плюс служебные варианты: `fadeUp` (`y 28→0` + opacity), `staggerParent`
(staggerChildren 0.1), `heroFocus` (исключение — hero-фото с blur 8→0).

### Ограничения blur (жёсткие)
- Появления текста — до **8px**.
- Анимируемый blur вне симуляторов — не более **3px**, фильтры точечно на
  элементах, **не** на контейнерах секций.
- Фокальная плоскость и фокус-идиома — до **3px** (обычно 1px).
- **Никогда** не вешать blur на полноэкранные изображения (цена GPU на мобильном).
  Исключения: hero-фото (одноразовое появление) и симуляторы зрения (это и есть
  смысл эффекта).

### Идиома фокуса (грамматика взаимодействия)
То, с чем взаимодействуют, — в фокусе; остальное отступает (blur 1–3px +
приглушение opacity). Применяется к спискам услуг/салонов, карточкам квиза,
полям формы, ленте брендов, «Шкале наводки», деталям чертежа, FAQ.
Реализована в CSS (`globals.css`, `@media (hover:hover)`) и точечно в JS.

### Тональные плоскости фона
- `offwhite #F6F4EF` — основной тёплый фон.
- `paper #FFFFFF` — белый «лист» с волосяными границами (тихая глубина).
- `ink #0D0D0D` — почти-чёрные акцентные секции.

### Запрещено навсегда (решение владельца)
Кислотный неон, частицы, бесконечно движущиеся градиенты, 3D-сцены, аляповатые
свечения, волнистые разделители. Разделитель по умолчанию — **волосяная линия**.
**Ослаблено ради премиума:** допустимы матовое стекло, **статичные** тональные
градиенты-«мосты» на стыках секций, мягкий кромочный блик стекла. Критерий —
дорогой editorial-вид, а не «эффект ради эффекта».

### Правило одной вечной анимации (ночь 2)
Любая бесконечная анимация **обязана** останавливаться вне вьюпорта
(IntersectionObserver) и в скрытой вкладке (visibilitychange); одновременно в
кадре их не больше двух. Сейчас бесконечны только: пульс подсказки скролла в hero,
лента брендов, моргание глаз на 404. Всё прочее — отклик на действие, одноразовое
появление или привязка к скроллу.

## 6. Дизайн-токены

### 6.1 Палитра (`tailwind.config.ts`)
```
paper     #FFFFFF   чистый белый (карточки, контраст)
offwhite  #F6F4EF   основной тёплый фон
ink       #0D0D0D   текст
graphite  #6F6B64   вторичный текст
line      #E4DFD6   волосяная линия / границы
brand        #FD0000  графика: линии, eyebrow, крупный дисплейный акцент
brand-deep   #D40000  заливки кнопок, мелкий красный текст (контраст AA ≥ 4.5)
brand-dark   #B80000  hover заливок
```
**Правило красного:** `brand` — только графика (линии, eyebrow, акценты).
`brand-deep` — заливки кнопок и мелкий красный текст. Выделение текста (`::selection`)
— `#FD0000` на белом.

### 6.2 Типографика
- **Дисплей/заголовки:** `font-serif` → `var(--font-display)` = `Literata`
  (вариативный серив, ось `opsz`, кириллица). Ось `opsz` — носитель «наводки»:
  motion анимирует CSS-переменную `--opsz` числом, строка читает её через
  `style={{ fontVariationSettings: '"opsz" var(--opsz,72)' }}` (сам
  `fontVariationSettings` motion не анимирует — поэтому переменная).
- **Текст:** `font-sans` → `Manrope` (300–700, кириллица).
- **Display-шкала** (clamp, адаптив):
  `display-xl` clamp(3rem, 8.5vw, 8rem); `display-lg` clamp(2.5rem,6vw,5.25rem);
  `display-md` clamp(2rem,4.5vw,3.75rem).
- `max-w-shell: 1280px`; `letterSpacing.eyebrow: 0.28em`;
  `transitionTimingFunction.soft: cubic-bezier(0.16,1,0.3,1)`.

### 6.3 Тайминг (`lib/motion.ts`)
- `EASE = [0.16, 1, 0.3, 1]` (editorial ease-out) — базовый везде.
- `DURATION = { fast: 0.3, base: 0.6, slow: 0.9 }`.
- `VIEWPORT = { once: true, margin: "-80px" }` — общий триггер `whileInView`.

### 6.4 Типографская гигиена русского текста (закон контента)
«Ёлочки», длинное тире « — », неразрывные пробелы после коротких предлогов/союзов
и в связках («20 минут», «−6 дптр», «г. Ташкент»). Правится **в строках контента**
(`content/home.ts`), **не** рантайм-регэкспами.

## 7. Глобальные системы

### 7.1 `src/app/layout.tsx`
- Подключает шрифты (`literata.variable`, `manrope.variable` на `<html lang="ru">`).
- **SEO:** `metadata` (title-template `%s · Оптимист`, description, keywords,
  openGraph, twitter, robots index/follow), `viewport.themeColor #F6F4EF`,
  `metadataBase https://optimist-optics.uz`. OG/Twitter картинки — файлы в `app/`.
- **JSON-LD** schema.org `Optician`: имя, телефоны, e-mail, головной адрес как
  `address`, остальные филиалы как `department`, `openingHoursSpecification`.
- **Skip-link** «К содержанию» (`#main`) — первый фокусируемый элемент.
- Дерево провайдеров:
  `IntroProvider → SmoothScroll → [Header, SectionRail, .page-shell[main#main, Footer]]`.
  Хром (шапка, «Шкала наводки») живёт **вне** `.page-shell` — при открытом мобильном
  меню `.page-shell` слегка сжимается (`scale(.985)`), а хром остаётся.

### 7.2 `src/app/globals.css`
- Базовые цвета через CSS-переменные, фон `offwhite`, `overflow-x: clip` на
  html/body (страховка от горизонтального скролла, не ломает Lenis).
- **Зерно:** `body::after` — фиксированный SVG-`feTurbulence` поверх всего,
  `opacity .022`, `z-100`, `pointer-events-none` (дорогая фактура; при пиксельном
  замере шва multiply его временно отключают в скрипте).
- Тонкий скроллбар (8px, ink/20→ink/40). `scroll-margin-top: 6rem` под фикс-шапку.
- **Прелоадер-failsafe:** `.intro-failsafe` — CSS-анимация, растворяющая оверлей
  через ~5 с без JS.
- **Стили Lenis** (рекомендованные).
- **Marquee:** `.marquee-track { will-change: transform }` (двигает JS-rAF).
- **Фокус-идиома** (только `@media (hover:hover)`): `.focus-list:hover
  .focus-item:not(:hover)` → opacity .45 + blur 1px; то же для `.marquee-group`,
  `.rail-list`, формы (`.form-focal:focus-within .form-field:not(:focus-within)` →
  opacity .55, **без blur** — текст должен читаться).
- **Система стекла** `@layer components` — см. §9.3.
- **reduced-motion:** глобальный сброс анимаций/транзишенов до 0.001ms, отключение
  blur в фокус-идиоме, `transform:none` для `.page-shell`.

### 7.3 `SmoothScroll` (`components/smooth-scroll.tsx`)
- Создаёт Lenis (`duration:1.2, smoothWheel:true`) — **только если нет**
  `prefers-reduced-motion`. Гоняет `requestAnimationFrame`.
- Экспортирует контекст `LenisContext` + хуки `useLenis()` и `useScrollVelocity()`
  (MotionValue скорости из события Lenis; при reduced-motion навсегда 0).
- Перехватывает клики по `a[href^="#"]`: плавно везёт к якорю с `offset: -80`
  (под шапку); по прибытии шлёт `window` событие `anchor-arrive` с id секции
  (его слушает `MotionFocus` — якорный фокус-пульс). Если секции нет на странице
  (например, мы на 404) — уводит на `/#id`. `#main` дополнительно переносит фокус
  (a11y). При reduced-motion — нативный `scrollIntoView`.

### 7.4 Прелоадер «op» (`components/ui/intro.tsx`)
- **Только на главной** (`usePathname() === "/"`); на 404 и прочих не рендерится
  вовсе (даже на сервере).
- Контекст `useIntroDone()` — весь hero ждёт его (`introDone`).
- **Решение «играть/нет»** (кэшируется на уровне модуля, защита от StrictMode):
  смотрит на **тип навигации** `performance navigation.type`:
  - `reload` → играет всегда;
  - `back_forward` → не играет;
  - обычный переход → играет только если пришли извне (referrer чужого origin или
    пустой); внутренний переход того же origin — не играет.
  - `prefers-reduced-motion` → сразу `done`.
- **Сценарий ≤1.8 с** (SVG «op», обводка): окружность «o» рисуется (pathLength),
  «p» с задержкой, ножка, зрачки-точки `#FD0000` вспыхивают (pop), оба «глаза»
  моргают (scaleY 1→0.08→1), пауза, растворение (delay 1.4, dur 0.4). Клик —
  пропуск. Зрачки/моргание — авторская версия владельца, **промптам не менять**.
- **Жёсткий таймаут 2.2 с** флипает `phase=done` при любом сбое (холодная

### 7.8 Переход маршрутов (`src/app/template.tsx`)
- `template.tsx` перемонтируется на каждой смене **маршрута** (не на hash-навигации).
- **Главную (`/`) НЕ оборачивает** (`if (pathname === "/") return children`):
  transform/filter/opacity на обёртке создали бы stacking context и сломали бы
  multiply-бленд FloatFrame; у главной свой прелоадер и масочные reveal'ы.
- Вторичные страницы (404 и будущие) получают «наведение резкости»:
  `opacity 0→1 + blur(8→0) + y 14→0 + scale .992→1`, dur 0.6 (0 при reduced).

### 7.9 Гидрация: `useReduceAfterMount()` (`lib/use-reduce-after-mount.ts`)
Сервер не знает `prefers-reduced-motion` и всегда рендерит анимационную ветку.
Хук до маунта возвращает `false` (серверная ветка), честное значение — после
гидратации. **Использовать только там, где `reduce` влияет на разметку/inline-
style** (иначе hydration-mismatch). Для логики в эффектах — `useReducedMotion`
напрямую. Этот гейт стоит во всех компонентах, ветвящих рендер по reduce
(Reveal, Eyebrow, Section/DrawnBorder, FocalSeam, Services, Anatomy, Faq и т.д.).

## 9. Подписные эффекты — детально

### 9.1 FloatFrame — «парящие оправы» (`ui/float-frame.tsx`)
Фото оправы на белом фоне лежит прямо на странице через **`mix-blend-mode:
multiply`** (белый фон кадра растворяется в фоне секции).

**Четыре факта физики (НЕ нарушать, см. CLAUDE.md):**
1. Blend смешивается с фоном внутри своего stacking context. Любой
   `transform/filter/opacity` на **обёртке** создаёт новый context и покажет белый
   прямоугольник. Поэтому фон цвета секции лежит **внутри** транформ-слоя и едет
   вместе с кадром; **все** фильтры — одним `useMotionTemplate` на самом `<img>`
   (фильтр элемента применяется до смешения — законно).
2. Сток-«белый» в реальности 248–253 → после умножения призрак. Лечение —
   нормализация файла до честного `(255,255,255)` (`scripts/normalize-white.ps1`).
3. Multiply только затемняет — белые блики исчезают. Отбирать матовые/тёмные/
   графичные оправы.
4. Лёгкое потемнение компенсируется `contrast(1.02–1.05)` (ручка `contrast`,
   по умолчанию выкл).

**Доставка:** `<Image unoptimized>` — оптимизатор Next перекодирует в WebP/AVIF и
YUV-сдвиг сместил бы белую точку 255→254 (шов). Размеры явные из
`FLOAT_INTRINSIC` (`content/photos.ts`), не `fill`.

**Ручки (props):** `slot, widthClass, className, sizes, rotate, parallaxSpeed
(<1 — отстаёт), rotateDrift (±2°), cursorTilt (±1.5°/±6px за курсором, desktop),
contrast, shadow ("natural"|"ellipse"), priority, entrance ("focus"|"none"),
entranceWaitIntro (hero ждёт прелоадер), focal ("scroll": ≤2px у кромок),
exitDefocus (рэк-фокус на выходе), exitScale (прощальное сжатие), sectionTone
("offwhite"|"paper"), draggable (только hero/desktop: ±40px, пружинит назад),
gyro (только Android: DeviceOrientationEvent есть, requestPermission не функция)`.
- Фильтры — десктопная роскошь (`filtersOn = desktop && !reduce`); все слагаемые
  (entrance/focal/exit/contrast) собираются в **один** `filter` через
  `useMotionTemplate`. Транформы (parallaxY, tilt, rotate, scale) — отдельным слоем.
- Живая тень `shadow="ellipse"` — div с radial-gradient под картинкой, отстаёт
  (×0.92), при cursorTilt слабеет/расплывается. **Никакого drop-shadow на blend.**
- Статичные ветки (reduce/мобайл) задают стили **явно** (`{rotate}`,
  `{opacity:1, filter:"none"}`) — motion не стирает уже выставленные inline-стили,
  иначе оправа замёрзла бы на opacity 0.

**Правила деко-оправ:** `aria-hidden`, `pointer-events-none`, не пересекают текст
(проверять 1024/1280/1440/1920), z под контентом и под «Шкалой наводки» (z-40),
**≤5 на сайт** (5 действующих: deco-1 — Салоны и Коллекции; deco-2 — Экспертиза;
deco-3 — О нас и Услуги), на мобиле скрыты, cursorTilt — только у героя.
**Левитация (бесконечное покачивание) запрещена** — вся жизнь от скролла/курсора.
**Запрещено** оборачивать FloatFrame в `FocalPlane` и любые filter-обёртки.

### 9.2 VisionSim — симулятор зрения (`ui/vision-sim.tsx`)
Вертикальная линия делит кадр: слева — мир без коррекции, справа — в очках.
- **Физика блюра** линейна по диоптриям и пропорциональна ширине кадра:
  `B(px) = severity × blurCoeff × width`, кламп ≤18px (`BLUR_MAX`). Так телефон и
  десктоп деградируют одинаково *относительно* кадра. Лёгкая потеря контраста
  `saturate 1→0.85` (`SAT_LOSS`).
- **Дискретность:** позиция шторки — `useMotionValue` (0–100%), значение диоптрий
  снапится к ступеням (`snapAbs`). Шторка скользит плавно через `clip-path`
  (дёшево), blur пересчитывается **только на границах ступеней** (`transition
  180ms`) — пофреймового blur нет.
- **Маска глубины** (`depthMask`, только улица): низ кадра (близкая земля) резче
  дальнего плана — у близорукого есть «дальняя точка».
- **Управление:** drag/клик в любом месте (`pointer` + `setPointerCapture`,
  `touch-action: pan-y` сохраняет вертикальный скролл); клавиатура на линии
  (`role="slider"`, ←/→ ступень, Home/End — 0/максимум; ARIA-числа со знаком,
  `aria-valuetext` со склонением «минус 2,5 диоптрии»). Модальность фокус-кольца
  ведётся вручную (`kbFocus`) — кольцо `brand` только клавиатуре.
- **Приглашающий толчок** (`nudge`, только верхняя шторка): через 1.2 с после входа
  во вьюпорт линия сама проходит одну ступень и возвращается (один раз, если не
  тронули).
- **Гаптика** (`navigator.vibrate(6)` на снапе ступени, не чаще раза в 40 мс,
  только Android/при взаимодействии/не reduced).
- Капсула диоптрий едет с линией (у краёв прижимается), угловые подписи
  «Без коррекции»/«В очках», подпись состояния — кроссфейд 200 мс.

### 9.3 Стекло (glassmorphism) — `globals.css @layer components`
Единый рецепт, применять **точечно** (хром, подписи на фото, тёмные секции) — не
на всё (backdrop-filter дорог; на плоском offwhite стекло почти не читается).
Слои: тинт + `backdrop-filter blur(16–18px) saturate` + волосяная **светящаяся**
кромка 1px + верхний внутренний блик (`inset 0 1px`) + мягкая тень глубины.
**Блюр никогда не анимируется.**
- **`.glass`** — светлое матовое (хром-шапка, PathCard «Подбора»).
- **`.glass-dark`** — тёмный тинт поверх фото (затемняет фон): бейджи/подписи на
  снимках (ярлык Collections, капсула Atmosphere, мобильная кнопка-линза).
- **`.glass-on-dark`** — светящаяся белая плёнка для карточек на ink-фоне (тёмный
  тинт там невидим): панель формы записи в CTA.
- **`.glass-sheen`** — градиентная кромка-блик по верх-левой грани (masked
  `::before`). Вешать вместе с любым из трёх.
- **Деградации обязательны:** `@supports` без backdrop-filter → плотная заливка;
  `prefers-reduced-transparency: reduce` → плотная заливка. Кромочный блик
  (`inset 0 1px`) остаётся всегда.
- **Запрет:** не оборачивать FloatFrame в backdrop-filter/filter — ломает multiply.
  Стекло вешать на **отдельные** соседние элементы.

### 9.4 FocalSeam — «шов наводки» (`ui/focal-seam.tsx`)
Переход между **главами** в грамматике сайта. Волосок наводится из центра к краям
(`scaleX 0→1` от центра), в центре — фокус-метка-линза (кольцо со зрачком `brand`,
тот же мотив, что у кнопки навигации — связывает систему), проявляется из расфокуса
(blur→0). **Не вечная** — одноразовое появление при входе во вьюпорт. Ставится
**только на стыках глав** (`page.tsx`, сейчас 2 штуки), мотив работает редкостью.
`tone="dark"` — светлая метка над тёмными секциями. reduce — статичная метка.

### 9.5 FocalPlane — фокальная плоскость страницы (`ui/focal-plane.tsx`)
Изображение резко в центре вьюпорта и мягчеет к кромкам (`blur 0→max`, бюджет
≤3px). Активна только при `(pointer:fine) и ≥1024px и !reduced`. Это отдельный слой
**вокруг изображения** — не вешать на элементы с hover-scale/параллаксом/своим
filter (и **никогда на FloatFrame**). Используется в Collections и Atmosphere.

### 9.6 LensLoupe — лупа-линза (`ui/lens-loupe.tsx`)
Подписной эффект Collections: круглая лупа (`SIZE=196px`, `ZOOM=1.85`) следует за
курсором и увеличивает фото. Оверлей **внутри** карточки-ссылки: ловит
`pointermove`, но клики всплывают к `<a>` (навигация и group-hover целы); позиция
пишется в `style` через `rAF` (без React-ре-рендеров). Только desktop/`pointer:fine`;
reduced/тач — не рендерится.

### 9.7 MotionFocus — velocity-резкость заголовков (`ui/motion-focus.tsx`)
Оборачивает **заголовки с масочным появлением** (не focusIn-элементы — конфликт по
filter, и не изображения). При быстром скролле заголовок «плывёт» (blur ≤2px от
`|velocity|`) и наводится на резкость при остановке. Плюс **якорный фокус-пульс**:
по событию `anchor-arrive` (Lenis доехал до секции) заголовок целевой секции один
раз наводится (blur 3→0, ~600 мс). Оба источника идут через один MotionValue
(берётся максимум). Только desktop/`pointer:fine`/`!reduced`.

### 9.8 PulseWord (`ui/pulse-word.tsx`)
Слово-акцент манифеста: при первом проходе через центр вьюпорта — однократный
фокус-пульс (blur 2→0, 500 мс). IntersectionObserver `rootMargin: -50% 0 -50%`
(вьюпорт сжат в линию по центру). Desktop only.

## 10. Подбор по лицу (камера) — полный пайплайн

**Главный путь «Подбора».** Осознанное исключение из «без зависимостей»: один
пакет `@mediapipe/tasks-vision` (Face Landmarker, 478-mesh, WASM), ленивый.

### 10.1 Координация и этапы
- `sections/fit-quiz.tsx` грузит `ui/face-fit.tsx` через `dynamic({ssr:false})`.
- **`face-fit.tsx`** — координатор: `consent → camera`.
  - `FaceConsent` → согласие (приватность тремя пунктами, иконка-«глаз»). «Включить
    камеру» / «Лучше три вопроса» (→ квиз) / «К выбору».
  - `FaceCamera` → детекция → скан → результат.
- Любая деградация (нет getUserMedia / отказ / нет WebGL / старый браузер / модель
  не загрузилась) ведёт **в квиз** — без тупиков.

### 10.2 `ui/face-camera.tsx` — петля детекции и классификации
- `getUserMedia({facingMode:"user"})` → зеркальное `<video>` (`-scale-x-100
  object-contain` letterbox). На узких/тач устройствах ширина 480px вместо 640.
- **Петля `rAF` + `detectForVideo`** идёт только при видимой вкладке
  (`visibilitychange`) и секции во вьюпорте (IntersectionObserver). Детекция
  троттлится до ~30 fps (`DETECT_INTERVAL=33`). `detectForVideo` требует строго
  растущий ts.
- **Накопление чистых кадров:** `frameQuality` отбраковывает наклон/поворот/мелкое
  лицо/выход за кромку (`lib/face-shape.ts`); **стоп-движение** — кадр идёт в выборку
  только если голова неподвижна (смещение зрачков+нос < `MOTION_MAX=0.05` ipd).
  Подсказки качества (`faceFit.hints`) повышают долю чистых кадров.
- **Сходимость решения:** сначала наполняется окно медианы (`WINDOW=64`,
  прогресс до ~45%); затем требуется, чтобы один `primary` держался
  `STABLE_NEEDED=30` кадров подряд **И** был «уверенным» (зазор ≥ порога). Потолок
  `HARD_MAX=220` (~7 с) → отдать как есть. Так повторный замер у одного человека
  даёт тот же ответ.
- При фиксации: одноразовое «наведение на резкость» кадра (blur 8→0, 600 мс), запись
  `latestRef` продолжается (оверлей следит за лицом), окно больше не копит.
- **Standby:** при уходе секции из вьюпорта >8 с — `stopStream()` (треки + окно +
  ландмарки), экран «Камера на паузе»; возврат поднимает камеру.
- **Чипсы силуэта-примерки** (8 силуэтов) — фокус-идиома, меняют чертёж на лице.
- **Прогресс-бар** анализа привязан к реальному накоплению.
- Результат → `FaceResult` + запись в `localStorage["optimist-fit"]`
  (`source:"camera"`).

### 10.3 Приватность — закон (исполнять буквально)
Видео и ландмарки живут **только в памяти вкладки**. Никаких сетевых отправок
кадров, сохранения, аналитики по лицу. При остановке камеры: `track.stop()`,
`estimator.reset()`, обнуление ландмарок/окна/опорных точек, `srcObject=null`.
Камера гаснет при «Выключить», размонтировании, долгом уходе секции из вьюпорта и
переходе на квиз.

### 10.4 Ассеты MediaPipe — ЛОКАЛЬНО (`lib/face-landmarker.ts`)
- Пакет тянется динамически: `import("@mediapipe/tasks-vision")` **внутри функции**
  (не на верхнем уровне) — тяжёлый WASM не попадает в стартовый бандл `/`.
- `FilesetResolver.forVisionTasks("/mediapipe/wasm")`,
  `modelAssetPath: "/mediapipe/face_landmarker.task"` — ноль внешних обращений
  (среда за сетевым фильтром + обещание приватности). Ассеты закоммичены в репо
  (≈37 МБ).
- Singleton-промис, GPU delegate с CPU-фолбэком,
  `outputFacialTransformationMatrixes: true`. При ошибке промис сбрасывается
  (следующий вызов пробует снова; фолбэк вызывающего — квиз).

### 10.5 Классификатор формы лица (`lib/face-shape.ts`) — ПРИБЛИЗИТЕЛЕН
Чистые функции, без импортов (юнит-тест `face-shape.test.ts` исполняется
изолированно). 6 классов: `oval, round, square, long, heart, diamond`.
- **Признаки** (инвариантны к расстоянию): `R1` = длина лица / ширина по скулам
  (главный предиктор); `R2` = ширина лба / ширина челюсти (отделяет «сердце»);
  `R3` = выраженность скул (→ «диамант»); `jaw` = острота угла челюсти у gonion.
  Индексы 478-mesh в `I` (помечены «требуют проверки точности на реальных лицах»).
- **Классификация:** каждая форма — прототип в `PROTO`; `score = exp(−Σ w·(x−proto)²)`
  с весами `WEIGHT {r1:4, r2:6, r3:12, jaw:3}`, нормировка в проценты. Возвращает
  `primary/secondary`, `mixture` (зазор <15% — честно показываем смесь),
  `confident` (зазор ≥18% — «уверенно» vs «скорее всего»), `confidence`, `scores`.
- **Качество кадра** `frameQuality`: размер скул ≥16% кадра, точки не у кромки
  (EDGE 0.04), roll ≤8°, yaw-симметрия ≥0.84.
- **Оценщик** `createEstimator` — скользящее окно `TARGET_CLEAN=64`, решение по
  **медиане** отношений (убирает дрожание).

### 10.6 `ui/face-scan.tsx` — кино-скан (часть фокус-грамматики)
Поверх видео **только во время анализа**. Красные линии `#FD0000` (не свечение —
запрет): линия-сканер со следом 24px (треугольная волна ~1.6 с), вспышки узлов
mesh у текущей высоты линии, угловые брекеты-видоискатель (ink, «дышат»), бегущая
строка статуса (моноширинная). Прогресс честный: при потере/наклоне лица (`waiting`)
скан «ждёт» — линия/узлы гаснут, статус «Выровняйте лицо». Завершение ведёт
родитель. reduced-motion: статичная рамка-видоискатель + «Анализируем…».

### 10.7 `ui/frame-overlay.tsx` — МАТЕРИАЛЬНЫЙ рендер оправы (не обводка)
Эволюция по требованию владельца: обводка-линия читалась игрушечно → заменена на
материальный рендер. Оправа — это материал:
- 8 силуэтов через **провайдеры** `BUILDERS`: `round, oval, rectangle, square,
  clubmaster, aviator, catEye, geometric`. Каждый строит `FrameParts` (контуры линз
  Path2D, мост, дужки, опц. бровь/перекладина, флаг `metal`).
- **Линза в 6 слоёв:** (a) внешнее AO-кольцо отрывает ободок от кожи; (b) стекло-тинт
  с косыми отражениями (полупрозрачно — глаза видны); (c) тело-ободок вертикальным
  градиентом (металл-золото vs ацетат-тёплый-чёрный); (d) тубус-объём (радиальный
  свет сверху-слева + затемнение снизу-справа = круглое сечение валика); (e)
  спекуляр по верхней кромке; (f) тёмная фаска по проёму. Свет единый — сверху-слева.
- Металлические оправы несут силиконовые носоупоры на рычажках; у ацетатных
  переносица цельная.
- **Привязка к ландмаркам:** зеркало видео (`scaleX −1`) и рендер — в одной системе
  координат (инверсия x в `project`); масштаб через реальный отображаемый
  прямоугольник видео (поправка на `object-contain`); поворот головы — горизонтальное
  сжатие линз (`squashL/squashR` по смещению носа). Кроссфейд силуэтов 200 мс.
- Покраска троттлится до ~30 fps (`PAINT_MS=33`, материал дороже линии).
- Геометрия выверена на стенде `scripts/frame-preview.html` (headless-скриншот) и по
  референсам реальных оправ. Точка расширения — провайдеры. Потолок реализма у 2D —
  «AR-зазор»; снять полностью может только 3D (PBR + свет + слежение по матрице
  позы) — отдельная сборка.

### 10.8 `ui/face-result.tsx` — экран результата
«Наводится на резкость» (blur 6→0). Заголовок с грамматикой смеси («<форма>, с
лёгкими чертами <вторичной>»), метка уверенности словами. 1–2 рекомендованных
силуэта с абзацем «почему» (карта — `lib/fit-recommend.ts`, помечена ПРОВЕРИТЬ
ОПТОМЕТРИСТАМИ). Ручная правка формы чипсами (6 форм, `FaceIcon`). Сноска про
оптометриста → `#cta`. Telegram-share. Запись в localStorage — на стороне родителя.

### 10.9 `lib/fit-recommend.ts` — карта рекомендаций (ДРАФТ)
Общая для квиза и камеры. `recommend(face,use,character)` (квиз),
`recommendByFace(face)` (камера, только по форме), `overlayForFace(face)` (силуэт
по умолчанию). Связки «форма × характер → направление» помечены
`// ПРОВЕРИТЬ ОПТОМЕТРИСТАМИ до публикации` — не публиковать без специалистов.

## 15. Страница 404 (`app/not-found.tsx` → `components/not-found-scene.tsx`)
Единственная страница с игровым тоном. Шапка/подвал — из layout, прелоадер не
рендерится.
- **«op»-очки** (SVG) следят зрачками за курсором (`useSpring`, предел смещения
  14px; только `pointer:fine`, !reduced). **Моргание** глаз (scaleY 1→0.08, раз в
  ~6 с) — единственная бесконечная анимация страницы.
- **Таблица Сивцева**: строки убывающим кеглем И **нарастающим расфокусом** сверху
  вниз («404» резко → «Страница» blur .6px → «Потерялась» 1.6px → «Из виду» 3px,
  на грани зрения). Наведение на чарт (`group-hover`) снимает blur — «нашёл
  страницу». Blur статичный, ≤3px. `sr-only` дублирует текст.
- Кнопка `Magnetic` «Вернуться к ясности» → `/` (внутренний переход — прелоадер не
  играет).

## 16. Доступность и reduced-motion

- **reduced-motion** уважается на трёх уровнях: глобальный CSS-сброс
  (`globals.css`), Lenis не создаётся (нативный скролл), компоненты ветвят рендер
  через `useReduceAfterMount()` (или `useReducedMotion` в эффектах). Все
  симуляторы/квиз/камера/формы остаются **функциональными** без анимаций.
- Семантика: `radiogroup`/`radio`, `role="slider"` с ARIA-числами, `aria-expanded`/
  `aria-controls` (FAQ), `aria-live` (результаты, статусы), `aria-current`
  (навигация), skip-link, видимый `focus-visible:ring-brand` везде.
- Клавиатура: квиз (стрелки), симулятор (←/→/Home/End), аккордеон, чертёж (подписи-
  кнопки), карусель (стрелки).
- `prefers-reduced-transparency` → плотная заливка стекла.
- `hoverOnlyWhenSupported` — ховеры не залипают на тачах. Тач-варианты CTA в
  карточках показываются статично (`[@media(hover:none)]`).

## 17. Скрипты и приёмка (`scripts/`)
- **`shot-site.mjs`** — headless-Chrome скриншоттер dev-сайта (нужен `npm run dev`
  на :3000). Кадры из env `SHOTS` (поля `label/path/anchor|y/anchorOffset/w/dsf/h/

  blend-кадров до `(255,255,255)`. Обязательна для всех будущих кадров техники

- **`cdp-whitepoint.mjs`** — проверка белой точки отдаваемых битмапов (255, не 254).
- **`cdp-audit.mjs`** — пиксельный тест шва multiply (цвет внутри и снаружи границ
  картинки канал-в-канал, в покое и в движении; зерно на время замера отключается).
- **`cdp-hydration.mjs`**, **`diag-firstload.mjs`** — диагностика гидратации/первой
  загрузки. **`frame-preview.html`** — стенд рендера оправ.

## 18. Инварианты и «запрещено навсегда» (чек-лист перед правкой)

1. **FloatFrame** — никаких filter/transform/opacity на обёртке; фон секции внутри
   транформ-слоя; `unoptimized`; кадры нормализованы; не оборачивать в FocalPlane/
   стекло. Левитация запрещена. ≤5 деко на сайт.
2. **Стекло** — точечно; блюр не анимировать; деградации обязательны.
3. **Blur** — текст ≤8px (появления), анимируемый вне симуляторов ≤3px, никогда на
   полноэкранных фото (кроме hero-появления и симуляторов).
4. **Вечные анимации** — стоп вне вьюпорта и в скрытой вкладке; ≤2 в кадре.
5. **Прелоадер** — только на `/`; играет на reload и внешнем заходе, не играет на
   внутреннем переходе/back-forward; зрачки/моргание не менять.
6. **Главную (`/`) не оборачивать** в `template.tsx`.
7. **reduced-motion** — ветвить рендер только через `useReduceAfterMount()`.
8. **Вариативный шрифт** — «наводка» типографики через анимацию `--opsz` (не
   `fontVariationSettings`); шрифт должен иметь кириллицу (Literata — да).
9. **Приватность камеры** — буквально: ничего не уходит в сеть, всё стирается.
10. **Карты рекомендаций** (`fit-recommend.ts`, `home.ts` faceHeadline/directions) —
    ПРОВЕРИТЬ ОПТОМЕТРИСТАМИ до публикации.
11. **canvas-рендер** (оправы/линзы) доводить по PNG-скриншоту, не вслепую.
12. **Невидимая геймификация** — награда-момент, без очков/бейджей/прогресс-баров
    достижений.
13. **Один подписной эффект на блок**.
14. **Типографская гигиена** — править в строках контента, не регэкспами.
