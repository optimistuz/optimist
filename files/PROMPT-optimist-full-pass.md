## БЛОК 0 — конституция (CLAUDE.md)

Допиши в CLAUDE.md проекта раздел «Дизайн-концепция: Наведение резкости»:

- Сайт ведёт себя как зрение, которому подобрали очки: контент проявляется
  из лёгкого расфокуса в резкость. Это системный язык всего сайта.
- Словарь движения — ровно три глагола:
  1) `focusIn` — текст: opacity 0→1, y 24→0, blur(8px)→blur(0);
  2) `maskLine` — заголовки: построчная маска (y 110%→0 внутри overflow-hidden);
  3) `imageReveal` — изображения: scale 1.06→1 + opacity (БЕЗ blur).
- Ограничения blur: не более 8px, только на текстовых блоках, никогда на
  полноэкранных изображениях. Причина: цена фильтра на мобильном GPU.
- Подписные эффекты «Оптимиста»: Compare-слайдер «до/после», (после фото)
  Lens-лупа ИЛИ Focus Cards. Один подписной эффект на блок.
- Запрещено навсегда: неон, частицы, движущиеся градиенты, 3D-сцены,
  свечения, волнистые разделители. Разделители — только волосяные линии.
- Эффекты, требующие фотографий, не строятся до появления фотографий.
- Красный: `#FD0000` — только графика (линии, eyebrow, крупный дисплейный
  акцент); `#D40000` (`brand-deep`) — заливки кнопок и мелкий красный текст
  (причина: контраст AA).

Проверка блока: CLAUDE.md содержит раздел, сборка не затронута.

## БЛОК 3 — система движения «Наведение резкости»

3.1 `lib/motion.ts` — добавь варианты (existing не удалять):
```ts
export const focusIn: Variants = {
  hidden: { opacity: 0, y: 24, filter: "blur(8px)" },
  visible: { opacity: 1, y: 0, filter: "blur(0px)",
    transition: { duration: DURATION.slow, ease: EASE } },
};
export const maskLineChild: Variants = {
  hidden: { y: "110%" },
  visible: { y: "0%", transition: { duration: 0.9, ease: EASE } },
};
export const imageReveal: Variants = {
  hidden: { opacity: 0, scale: 1.06 },
  visible: { opacity: 1, scale: 1,
    transition: { duration: DURATION.slow, ease: EASE } },
};
```

3.2 `ui/reveal.tsx`: компоненту `Reveal` добавь prop
`variant?: "fade" | "focus"` (default `"focus"`), focus использует focusIn.
Новый компонент `RevealLines` для заголовков секций: принимает строку с `\n`,
рендерит каждую строку в `span.block.overflow-hidden` с внутренним
`motion.span` (maskLineChild), stagger 0.12 — тот же приём, что в hero.
Reduced-motion: статичный рендер (как в существующих компонентах).

3.3 Применение по секциям:
- Заголовки секций (services, expertise, collections, testimonials, cta) →
  `RevealLines` вместо текущих Reveal/обычного рендера.
- Body-абзацы и eyebrow → `Reveal variant="focus"` (текущие Reveal этим
  покрываются дефолтом).
- Карточки коллекций → обёртка с `imageReveal` (вместо fadeUp в RevealItem —
  добавь в RevealItem prop `variants` с дефолтом fadeUp и передай imageReveal
  в collections).
- ВАЖНО: blur — только на текстовых блоках. На карточках коллекций и любых
  изображениях blur не используется (для них imageReveal).

3.4 Hero: в `lineChild` добавь `filter: "blur(6px)"` → `"blur(0px)"` —
заголовок наводится на резкость при загрузке.

3.5 Манифест (positioning): подними кегль statement-абзаца с `text-display-md`
до `text-display-lg` — манифест должен звучать как разворот, а не как абзац
(приём Vivid+Co).

Проверка блока: tsc + build; в dev пролистай страницу — все появления
работают, ничего не мигает; reduced-motion (эмуляция в DevTools) показывает
статичную страницу.
