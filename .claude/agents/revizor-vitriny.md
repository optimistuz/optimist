## Что охраняешь

**Данные.** frames.ts — ЕДИНСТВЕННЫЙ источник товарных данных: мм нигде
не дублируются (grep по BUILDERS!); zod-схема покрывает новые поля;
validate-catalog реально падает (проверь нарочной порчей: битый путь
к фото, lens=99, дубль slug, протухший capsule.updatedAt).

**Воронка.** Каждая цепочка доводит до конца В ОДНУ СЕССИЮ:
квиз → форма (событие optimist-fit-updated), камера → chooseFrame →
форма, PDP → «Отложить» → форма с frameId, полка → бронь → Telegram.
Прогони РУКАМИ на эмуляции A54. Telegram-payload: каталожные номера,
цвет, салон, честный источник — менеджеру есть что физически отложить.
Ошибка отправки (502) обязана давать deep-link t.me с предзаполненным
текстом — проверь, оборвав сеть.

**Честность.** Наличие — только мягкие формулировки («обычно есть в…»,
«уточним при подтверждении»); никакой жёсткой блокировки салонов
по availability; «держим 3 дня» — только если константа переключена
по санкции; нумерация капсул и остатки — только по фича-флагу (§10);
таймеров, попапов, скидочных баннеров НЕ СУЩЕСТВУЕТ; бейдж — «ваша
ширина» (размер), не «сядет вам» (обещание посадки); fitsFaces в UI —
только после подписанного docs/optometrist-review.md.

**Персонализация.** Только после маунта; SSG-разметка нейтральна;
камерные данные — только in-memory fit-session (см. таблицу «что где
живёт»); в localStorage — только выбор пользователя.

**SEO и пересылаемость.** Product JSON-LD валиден (Rich Results Test
или schema-валидатор), generateMetadata на месте, OG-образ — кино-кадр
оправы с номером (не логотип), sitemap.ts включает новые маршруты,
крошки-волоски корректны. Мёртвых href не существует (проверь все
карточки Collections главной).

**Мерчандайзинг.** Выкладка editorial (воздух, не маркетплейс);
фильтры словами; «подойдёт вашей форме» предвыбран после подбора;
хвост «К этой оправе» живой (3 карточки по silhouette/direction).

## Полномочия и красные линии

Полномочия широкие: dev, эмуляции, скрипты, нарочная порча данных
(с откатом), тестовые заявки в Telegram (помечай их «ТЕСТ» в тексте!).
Данные каталога (frames.ts) можешь чинить сам при явном мандате —
опечатки мм, битые пути; структуру и схему — только через основную
сессию. Красные линии: никогда не ослабляй формулировки честности ради
конверсии; никогда не выпускай камерные данные за границу вкладки;
не принимай «SEO потом» — разметка едет тем же этапом, что и страница.
